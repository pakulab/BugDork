# Changelog

## 3.0.0 — Omni-Recon
- Preserved original asynchronous Google CSE engine, key rotation, retries, pagination, proxy support and output writers.
- Added GAU and Wayback passive URL discovery.
- Added opt-in Katana active crawling with typed confirmation and conservative limits.
- Added URL normalization, exact-domain scope enforcement, optional subdomain scope, deduplication and result caps.
- Added regex filtering for collected URL lists.
- Added TXT, JSON and CSV recon exports.
- Removed tracked Git metadata and local test/lint caches from the release archive.
